# Coordination Kit documentation

Start with [Getting started](guides/getting-started.md) to set up a repository or join a shared
workspace.

- [Guides](guides/README.md) walk through setup, operation, development and upgrades.
- [Reference](reference/README.md) defines commands, configuration, work files and runtime contracts.
- [Design](design/README.md) records current requirements, boundaries and their rationale.
- [Work](https://github.com/andornaut/coordination-kit/blob/main/docs/work/README.md) indexes
  requests, decisions and outcomes in the source repository.
