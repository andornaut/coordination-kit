# Reference

Use these pages to look up Coordination Kit interfaces and rules.

- [Commands](commands.md) covers CLI forms, options and results.
- [Configuration](configuration.md) defines workspace and project settings and state locations.
- [Libraries](libraries.md) lists public Node API subpaths.
- [Messages](messages.md), [registry](registry.md) and [scheduled reviews](review.md) describe
  communication, bindings and review delivery.
- [Store](store.md) describes durable work, approval, message and recovery records.
- [Work files](work-files.md) defines the work-item format, verification and index checks.

For setup and end-to-end workflows, start with the [guides](../guides/README.md).
