## Scope

A command with which a role enrolls itself in the work protocol from its own current state, without a hand-written enrollment input file.

## Criteria

- It derives the context and inspection receipt from the role's own journal, registry binding and canonical references.
- It publishes through the existing enrollment producer and refuses any role other than the caller's own.
- The enrollment receipt format does not change.
