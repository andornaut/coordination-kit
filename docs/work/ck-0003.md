## Scope

Under an active work protocol, `message send` also publishes the canonical original, `message reconcile` publishes the recipient handling receipt, and `work start` publishes the start of approved work.

## Criteria

- Each shortcut uses the existing protocol producers, fences and replay rules.
- Without an active protocol each command behaves as it does today.
- A failure after one step reports which records were committed, so the caller reconciles before retrying.
