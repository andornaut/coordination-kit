## Scope

`validateProjectConfig` rejects unknown keys under delivery-kit's `git`, `gate`, `resources`, `ci` and `deploy` sections, although this kit reads only `reports`. A new delivery-kit setting then breaks inbox snapshots, scheduled reviews and event flushes until this kit is released.

## Criteria

- This kit validates `reports` and the top-level shape, and passes the other sections through unread.
- delivery-kit's own validation of its sections is unchanged.
- `docs/configuration.md` states which sections each kit validates.
