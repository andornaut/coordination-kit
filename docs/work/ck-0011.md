## Scope

Packaged docs are checked only by the `test` and `package` jobs, which a docs-only change skips. A docs-only change can drop or add a packaged doc without updating `package.json` `files`, and CI stays green until the next code change.

## Criteria

- The always-run lint job checks that the packaged docs and `package.json` `files` agree.
- Docs-only changes still skip build, test, contract and package.
