## Scope

Packaged docs are checked only by the `test` and `package` jobs, which a docs-only change skips. A docs-only change can drop or add a packaged doc without updating `package.json` `files`, and CI stays green until the next code change.

## Criteria

- The always-run lint job checks that the packaged docs and `package.json` `files` agree.
- Docs-only changes still skip build, test, contract and package.

## Decisions

- `scripts/docs-check.ts` (`npm run lint:docs`) runs in the always-run lint job, `make lint` and `npm run lint`; the path classifier is unchanged, so docs-only changes still skip build, test, contract and package.
- `package.json` `files` is the single list of packaged docs: each entry is an exact path, a `!` entry is a deliberate exclusion, and package inspection and the packed-file test read the same list.

## Outcome

Lint fails when a listed doc is missing, when a `docs/*.md` or `docs/design/*.md` file is neither listed nor excluded, or when a packaged doc links by relative path to an unpackaged file. Unit tests cover each case and the current tree.
