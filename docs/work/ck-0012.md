## Scope

The README, `docs/work-files.md` and the design summaries link to `docs/work/`, which is not packaged, so those links break in the npm package.

## Criteria

- Links from packaged docs to `docs/work/` use the repository URL.
- The packaged-docs check fails on a relative link to an unpackaged file.
