## Scope

The README, `docs/work-files.md` and the design summaries link to `docs/work/`, which is not packaged, so those links break in the npm package.

## Criteria

- Links from packaged docs to `docs/work/` use the repository URL.
- The packaged-docs check fails on a relative link to an unpackaged file.

## Decisions

- Packaged docs link to `docs/work/` by `https://github.com/andornaut/coordination-kit/blob/main/docs/work/`, which resolves from the npm package.
- `work check` accepts an index row linked by the repository's blob URL on `main`, derived from the `package.json` `repository` field, as well as a relative path; a URL of another repository is `index-link-unresolved`, so the design index tables can use the URL form.

## Outcome

The README, `docs/work-files.md` and every design summary link to work files by repository URL, and the packaged-docs check rejects a relative link to an unpackaged file. Tests cover the URL form, a URL to a missing work file, another repository's URL and the relative form.
