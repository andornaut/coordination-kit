## Scope

Protocol commands map every error code outside an allowlist to `protocol-operation-failed`
(`src/commands/protocol.ts`), so an input-shape mistake, such as `writer` in place of `context`
for a work command, gives no hint of the cause. Report the cause without exposing input values.

## Criteria

- A missing or invalid input field reports a normalized code and the field path, for example
  `invalid-input` with `/context`.
- An unexpected error keeps a generic code and names the operation stage that failed.
- No error output contains input values, bodies or secrets.
- Existing error codes and exit codes do not change.
