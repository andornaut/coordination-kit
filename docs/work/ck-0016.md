## Scope

Implement the coordination-kit part of Phase 1 in the [simplification design](../design/simplification.md#phase-1-stable-entry-points-and-growth-stop): `claude channel` also watches a per-conversation wake file, `--version` prints the version and dist sha256, `review deliver` and `events flush` give the runner a typed JSON seam, and automatic boundary capture is off by default.

## Criteria

- The runner can deliver reviews and flush events through the installed CLI with a typed `{status, detail}` result that carries the CLI version and dist sha256.
- A kit patch reaches Claude sessions on the stable channel path through `npm ci` plus `/mcp` reconnect, with no relaunch.
- Ledger growth from automatic capture stops; `--capture` restores it.
- Legacy spool delivery keeps working unchanged.

## Decisions

- Internal failure prints no stdout line and exits 1 with one stderr line; `cli-error` stays in
  the token set for the runner to report a failed call, and the CLI never prints it.
- `review deliver` records each typed result per (game, slot) under
  `bus/unblock/review-deliver/`, so a repeat prints it without calling the seam. Lock contention
  is not recorded, as the seam never recorded it.
- Reason tokens come from the receipt status, then fixed rules over the existing deferral texts.
  `outbox-unreadable` is the one addition, because an unreadable event file matched no token.
- Capture is a per-call `--capture` flag rather than a `config.json` switch, because a new key
  there is refused by every older reader, including the runners that bundle 1.1.
- From source the digest is 64 zeros; a build hashes the running `dist/cli.js` once per process.
- A wake present when the channel starts sets the baseline and is not announced, so a reconnect
  never repeats an old wake; reviews still list undelivered messages.

## Outcome

coordination-kit 1.2.0 adds `review deliver`, `events flush` and `--version --json` with typed
results carrying the CLI identity, a wake-file watcher in `claude channel` beside the unchanged
legacy spool drain, `writeWakeFile` for Phase 2, and opt-in `--capture`. Enrollment, boundaries
and mutating protocol commands pass with capture off. The example channel configuration uses the
stable `node .../dist/cli.js` path that `npm ci` updates in place.
