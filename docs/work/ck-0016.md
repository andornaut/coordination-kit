## Scope

Implement the coordination-kit part of Phase 1 in the [simplification design](../design/simplification.md#phase-1-stable-entry-points-and-growth-stop): `claude channel` also watches a per-conversation wake file, `--version` prints the version and dist sha256, `review deliver` and `events flush` give the runner a typed JSON seam, and automatic boundary capture is off by default.

## Criteria

- The runner can deliver reviews and flush events through the installed CLI with a typed `{status, detail}` result that carries the CLI version and dist sha256.
- A kit patch reaches Claude sessions on the stable channel path through `npm ci` plus `/mcp` reconnect, with no relaunch.
- Ledger growth from automatic capture stops; `--capture` restores it.
- Legacy spool delivery keeps working unchanged.
