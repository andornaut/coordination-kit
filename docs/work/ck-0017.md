## Scope

Implement the coordination-kit part of Phase 2 in the [simplification design](../design/simplification.md#phase-2-one-store-and-one-message-path): the SQLite store, `msg send|done|retain|status|history`, `inbox`, wake adapters, stored briefs and runner events, `events ingest`, and `store import|export` with the cutover and rollback procedure.

## Criteria

- Every send is durable before any native action, and recipients pull.
- A message closes with one write.
- Import keeps every original ID, body hash, link and evidence, with uncertain deliveries flagged `unconfirmed`.
- The Phase 2 exit criteria in the design hold.
