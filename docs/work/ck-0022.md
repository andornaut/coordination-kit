## Scope

Persist owner-authenticated explicit answers before filesystem writeback. Preserve exact binding, numbering, public text validation and unrelated prompt guards. Expose pending and failed Markdown projection and provide idempotent recovery, including unavailable worktrees and missing writeback.

## Decisions

- D1 (coordination-kit, 2026-11-21): The store records the exact answer before attempting writeback,
  superseding ck-0018 D7. Numbering waits for an available work file to preserve existing decision
  references. The owner can retry projection by question ID.

## Outcome

Questions retain their answers when work-file projection fails or is interrupted. The owner can
restore a missing decision line or diagnose a conflict through the projection result.
