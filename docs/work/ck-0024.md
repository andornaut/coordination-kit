## Scope

Add access-checked exact-ID body reads. Expose stalls by exact ID in the review brief and support explicit timed and next-review retention while preserving legacy dependency text.

## Implementation

- `msg status ID --include-body` reads the original for the sender, recipient or coordinator.
- The scheduled review compares stalled IDs with the previous brief and highlights new stalls.
- `msg retain --until ISO_TIMESTAMP` and `msg retain --next-review` record explicit boundaries.
  `--next-boundary TEXT` preserves existing dependency and hold records.
