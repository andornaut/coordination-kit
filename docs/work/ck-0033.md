An owner can pull all durable originals while the native notice remains queued. A new original
must reuse the outstanding notice guard until the exact wake has been verified as consumed.
Share the guard between native and tmux delivery for the same active binding. Preserve original
IDs, recorded uncertainty and existing review boundaries.

Source request: game-coordinator `gc-0020`.

## Outcome

Native wakes and guarded tmux reminders reserve the same active Codex role and conversation.
Inbox pulls leave the reservation active. Reconciliation needs both bounded queue inventory and
an exact consumed user item in native history. A guarded review retains the originals while
proof is unavailable. Claim responses give the coordinator exact wake text with a receipt ID
for future tmux consumption checks.
