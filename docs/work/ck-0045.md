Wakes reach a role's current binding, including after a Claude `/clear` rebind.

- The Claude channel resolves the role's binding on each poll instead of fixing the
  conversation ID at start.
- At review time, send one native wake per recipient with unread originals, through one harness
  adapter: Claude through its channel or native cross-session message, Codex through the control
  socket. This rearm path replaces the reminder claim and settle ledger and the urgent-attention
  messages, which are deleted. The store question guard replaces the decision-marker clearance.
- The brief prints the native-visibility line only when a supported survey exists, groups stalled
  and overdue exceptions per recipient (count, oldest ID, age) and keeps the full IDs in
  `review show`.

Source request: Game Coordinator, package A.
