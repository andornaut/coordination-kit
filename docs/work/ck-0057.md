Accept an unbound local caller's message to a registered recipient and label the
sender as unbound. The message is ordinary queue traffic. Preserve recipient
guards and the binding requirements for all other commands.

## Outcome

The sender is shown as `[unbound]`. The recipient can read and handle the
original after a store reopen or rebuild.
