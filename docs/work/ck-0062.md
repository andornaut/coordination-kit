Distinguish a verified queued Codex wake from unavailable queue evidence. Show the
earliest associated wake alongside the latest on exact status reads. Let recipients
attach evidence when retaining an original and record the next boundary. Preserve
native question and hold checks, payload visibility and recipient-owned disposition.

## Outcome

Coordination Kit 7.4.0 reports a verified earlier queued notice separately from
unavailable queue evidence. Exact message status shows the first and latest wake
associations. Recipients can record evidence with an explicit retention, which
keeps an owner deferral separate from a collected original awaiting disposition.

The release passed 755 unit tests, 11 contract tests and both required hosted checks.
A read-only check against the operating store verified the first and latest wakes
for an already handled original. Existing guards and body permissions apply.
