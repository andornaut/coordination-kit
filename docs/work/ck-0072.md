entry points easy to find, use consistent dependency boundaries, and favour
direct interfaces. Verify the CLI, library subpaths and persisted formats
against their existing contracts.

## Outcome

Grouped CLI handlers, configuration, file utilities, store records and
compaction by responsibility. Shared store setup now has its own module,
and maintenance and message commands have separate entry points. The README
maps the new layout. Before and after builds matched the public exports and
12 representative CLI scenarios.
