Audit command forms, the parser, and how each handler uses its options.
Default safe previews and uniquely determined selections. Retain explicit
values where they identify a target, supply evidence, grant authority, or
choose between materially different actions.

## Outcome

Documentation compaction plans and store retirement previews by default.
Omitted message retention boundaries use the next scheduled review.
Registration and proposals default to the sole configured role, and
question answers can reuse recorded work. Help identifies explicit and
conditional options, including the shared root override.
