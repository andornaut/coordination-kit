projects may opt in to shared GitHub Issues tasks and link native PR reviews.

41,368 events, 27,405 projected rows, two archived journals and 24 compacted
message views on an independent fleet restore. The released runtime bytes
match the replayed build.

bundled Coordination Kit 8.0.0. All three reported current observers and the
exact shared Coordination Kit 8.0.0 CLI. The journal head before and after
installation matched the fresh independent restore at sequence 43,825.

After the verified runtime switch, Ansible Control was reinstalled with the
exact 8.0.0 artifact. The new role has an empty task list and no legacy
database in its active state. The project configuration and 29 existing
working tree changes matched their pre-install fingerprints. The Game
Coordinator tracks the first post-cutover review at the existing 18:30
Toronto slot.
